# Supported Cube Versions

Use this information to find out what [Cube](https://github.com/cube-js/cube) versions are currently supported by Embeddable's cloud platform.

 - To switch between Cube versions, learn more [here](/dashboards/saving#cube-version).
 - To bring your own version of Cube, learn more [here](/data/bring-your-own-cube).

 - **Supported**: recommended for production use.
 - **Experimental**: available for testing, and can be enabled on a dashboard-by-dashboard basis using the [Version Picker](/dashboards/saving#cube-version) at the top of the dashboard builder. Not recommended for production dashboards yet.
 - **Deprecated**: still available, but will be removed in the future.

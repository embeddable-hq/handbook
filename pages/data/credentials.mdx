# Database credentials

<Callout emoji="💡">
  Using **Cube Cloud** or your own **Cube Core** deployment instead of Embeddable's built-in Cube? See [Bring your own Cube](/data/bring-your-own-cube) — this page does not apply to you.
</Callout>

Under the hood, Embeddable relies on an open-source library called [Cube](https://cube.dev/docs/product/configuration/data-sources) to connect to your database.

Below are the `type` and `credentials` fields you’ll need when [connecting your database](./connect-your-database). You can also set an optional [`concurrency`](./connect-your-database#connection-concurrency) field on the connection itself (alongside `type` and `credentials`, not inside it) to control how many connections Cube opens to your database.

### Athena
[Cube docs](https://cube.dev/docs/product/configuration/data-sources/aws-athena)
```javascript
type: 'athena',
credentials: {
  accessKeyId: '...',
  secretAccessKey: '...',
  region: '...',
  // S3OutputLocation: '...',
  // workGroup: '...',
  // catalog: '...',
  // schema: '...',
}
```

### BigQuery
<Bruno/>
[Cube docs](https://cube.dev/docs/product/configuration/data-sources/google-bigquery)
```javascript
type: 'bigquery',
credentials: {
  projectId: '...',
  credentials: { // content of service-account.json
    "type": "service_account",
    "project_id": "...",
    // etc.
  }
}
```
To use Workload Identity Federation (`"type": "external_account"`) instead of a service account key, [contact us](mailto:support@embeddable.com) to enable it.

### Microsoft Fabric
[Cube docs](https://docs.cube.dev/admin/connect-to-data/data-sources/ms-fabric)
```javascript
{
  "type": "msfabric",
  "credentials": {
    "server": "...",
    "database": "...",
    "tenantId": "...",
    "authType": "...", // ActiveDirectoryPassword or ActiveDirectoryServicePrincipal
    "username": "...",
    "password": "...",
    "clientId": "..."
  }
}
```

- `ActiveDirectoryServicePrincipal`: set `username` to the client ID and `password` to the client secret. Do not send `clientId`.
- `ActiveDirectoryPassword`: set `username` and `password` to the user's credentials, and also set `clientId`.

### Snowflake
[Cube docs](https://cube.dev/docs/config/databases/snowflake)
```javascript
type: 'snowflake',
credentials: {
  account: '...',
  warehouse: '...',
  database: '...',
  username: '...',
  "authenticator": "SNOWFLAKE_JWT",
  "privateKey": "-----BEGIN PRIVATE KEY-----\n........\n-----END PRIVATE KEY-----"
  // password: '...',
  // oauthToken: '...',
  // role: '...',
  // region: '...',
}
```
To generate a private key:
```
openssl genrsa 2048 | openssl pkcs8 -topk8 -inform PEM -out rsa_key.p8 -nocrypt
```
To extract the public key:
```
openssl rsa -in rsa_key.p8 -pubout -out rsa_key.pub
```
